problem: >
  Affiliate marketing is a long chain of small jobs: find programs worth
  promoting, read the terms, watch what is trending, write the post, build the
  page, ship it, then measure. Every one of those jobs is now something an agent
  could do. Almost nobody had written the instructions down.
approach: >
  One skill per stage of the funnel, each a plain SKILL.md file an agent reads
  before it acts. No SDK, no runtime, no lock-in: the format is text, so the
  same skills run in Claude Code, Cursor, Gemini CLI, Windsurf or any tool that
  reads AGENTS.md. Adding a skill means adding a file.
stage: >
  Live and open source under MIT since 2026-03. Installed with one npx command.
  Three open issues, all about skill discovery in nested folders.
vision: >
  Agent skills become how operational knowledge is shipped, the way npm
  packages became how code is shipped. A marketer should be able to hand their
  agent a repo and have it work like someone who has done the job for years.
