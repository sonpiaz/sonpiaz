# Hey, I'm Son Piaz

I build infrastructure for people who run AI agents. Most of it is open source, and almost all of it exists because I needed it first.

Four manager agents each own one of these projects and start their own workers. Claude writes the specs and the reviews, Codex and Cursor do the construction.

### Products

| | What it solves |
|---|---|
| [**Kyma API**](https://kymaapi.com) | One key for the open and frontier models, with uptime you can check. Most gateways tell you a model is available; this one publishes what it measured per model and routes around the ones that are down. 3.19B tokens across 257,882 requests since April 2026. |
| [**Mandeck**](https://mandeck.dev) | A macOS terminal for running many coding agents at once. One agent opens a pane for another, hands it work and waits for the result, so a team of agents fits on one screen instead of twenty tabs. |
| [**Affitor**](https://affitor.com) | A SaaS brand that wants a partner program has to build the tracking first. Affitor turns a link into a click, a click into a lead, a lead into a sale, then calculates and pays the commission. Live, with brands on it. |
| [**Build to Own**](https://build2own.dev) | Vietnamese builders can follow AI tutorials for months and still ship nothing anyone pays for. Four weeks, a fixed deadline, a brief at the end of every session, and a public demo day. 140 builders in the first cohort. |
